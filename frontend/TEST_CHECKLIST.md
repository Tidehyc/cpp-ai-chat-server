## 一、环境准备

### 启动后端

```bash
# 方式 1：直接启动
cd /home/tide/workplace/cpp-ai-chat-server/build
./chat_server

# 方式 2：使用 Docker
cd /home/tide/workplace/cpp-ai-chat-server
docker-compose up -d
```

### 启动前端

```bash
cd /home/tide/workplace/cpp-ai-chat-server/frontend
npm install
npm run dev
```

### 访问地址

- **前端**: http://localhost:5173
- **后端 API**: http://localhost:8080
- **WebSocket**: ws://localhost:8080

### 环境检查清单

- [ ] 后端服务已启动，端口 8080 可访问
- [ ] 前端开发服务器已启动，端口 5173 可访问
- [ ] 浏览器打开前端地址无报错
- [ ] 浏览器控制台无严重错误
