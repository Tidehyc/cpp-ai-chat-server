## 📋 项目概述

**项目名称**：C++ AI Chat Server 前端

**技术栈**：
- React 18
- TypeScript
- Vite 5
- Tailwind CSS
- Zustand（状态管理）
- React Router 6
- WebSocket

**后端接口**：
- WebSocket 连接：`ws://localhost:8080`
- 通信格式：纯文本命令 + JSON 响应

## 🔧 后端命令映射

### 用户命令
```
/register <用户名> <密码>     # 注册
/login <用户名> <密码>        # 登录

```

/leave                       # 离开房间

```
/msg ai <消息>               # 私聊 AI
/preset list                 # 列出预设
/preset use <名称>            # 使用预设

```
/history <目标> [数量]        # 查看历史
/search <关键词>             # 搜索消息
/search from:用户             # 按用户搜索
/search in:#房间              # 按房间搜索

## ⚠️ 注意事项

### 登录流程
1. 用户输入用户名和密码
2. 发送 `/login <用户名> <密码>`
3. 后端返回：`✅ 登录成功！欢迎 <用户名>。TOKEN:<sessionToken>`
4. 前端提取 token 并保存到 localStorage
5. 跳转到聊天页面

### 自动登录流程
1. 页面加载时检查 localStorage
2. 如果有 sessionToken，发送 `/login <用户名> <sessionToken>`
3. 后端验证 token 有效性
4. 验证成功 → 保持登录状态
5. 验证失败 → 跳转登录页

### WebSocket 消息处理
- 后端返回 JSON 格式：
  ```json
  {
    "type": "system|private_message|room_message|ai_response|friend_list|online_users",
    "content": "消息内容",
    "from": "发送者",
    "to": "接收者",
    "timestamp": 1234567890
  }
  ```
- 前端需要解析并分发到对应的处理器

### 错误处理
- 网络断开时显示友好提示
- 登录失败显示具体错误原因
- 会话过期自动跳转登录页
- 消息发送失败保留在输入框
