### 四、消息广播（多客户端测试）

**需要两个客户端**：

**终端 1**：
```bash
./ws_client
/login user1 123456
/join testroom
```

**终端 2**：
```bash
./ws_client
/login user2 123456
/join testroom
```

#### 4.1 普通消息广播
终端 1 发送：
```
你好，有人吗？
```
- [ ] 终端 2 收到：`[user1]: 你好，有人吗？`

终端 2 回复：
```
我在！
```
- [ ] 终端 1 收到：`[user2]: 我在！`

#### 4.2 不同房间不广播
终端 1 在 `testroom`，终端 2 在 `otherroom`
终端 1 发送消息
- [ ] 终端 2 不收到消息
