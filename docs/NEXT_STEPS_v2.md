# 待验证清单项及工作计划（v2026-05-14）

## 优先级 1：关键功能验证

### 1.1 私聊历史回放 (UI 端验证)
**清单项**: 查看与某好友的私聊历史、消息不泄露

**验证方案**:
- 双账户（A、B）建立好友关系
- A 向 B 发送多条私聊消息（包含时间戳、文本、emoji）
- 切换到私聊窗口，验证历史记录完整显示
- 验证消息时间排序正确
- 验证第三方用户（C）无法查看 A-B 的私聊

**预期产出**: `ci_private_history_test.py` 脚本（Web UI 自动化验证）

---

### 1.2 WebSocket 自动重连状态显示
**清单项**: 自动检测连接状态、连接失败自动重连、连接状态显示

**验证方案**:
- 前端 UI 显示连接状态指示器（在线/离线/重连中）
- 模拟网络中断（关闭服务器或客户端连接）
- 验证 UI 显示"离线"或"重连中"状态
- 恢复连接后，验证状态变为"在线"
- 消息队列恢复正常

**预期产出**: `ci_ws_status_ui_test.py` 脚本（前端状态验证）

---

### 1.3 超时处理测试
**清单项**: AI 请求超时、数据库超时

**验证方案**:
- **AI 超时**: 设置极短超时时间，验证友好错误提示（不是原始异常）
- **数据库超时**: 延迟查询响应，验证连接不断裂
- 验证日志中记录超时事件

**预期产出**: `ci_timeout_test.py` 脚本

---

## 优先级 2：并发与数据一致性

### 2.1 并发好友请求
**清单项**: 同时发送好友请求、事务处理正确

**验证方案**:
- 两个客户端同时向对方发送好友请求
- 验证双方都收到请求
- 其中一个接受，另一个拒绝
- 验证最终状态一致

**预期产出**: `ci_concurrent_friend_test.py` 脚本

---

### 2.2 重复操作测试
**清单项**: 重复添加好友、重复加入房间

**验证方案**:
- 尝试两次添加相同好友 → 应拒绝第二次
- 尝试两次加入相同房间 → 应处理优雅
- 验证数据库无重复记录

**预期产出**: 集成到 `ci_boundary_test.py` 或新建 `ci_idempotent_test.py`

---

## 优先级 3：前端与主题

### 3.1 深色主题验证
**清单项**: 浅色/深色/系统三种模式、主题切换

**验证方案**:
- 打开设置页，验证主题选项可见
- 切换主题，验证 UI 颜色改变
- 验证主题选择持久化（刷新页面后保留）

**预期产出**: `ci_theme_test.py` 脚本（Playwright + 颜色检查）

## 优先级 4：错误日志

### 4.1 错误日志收集
**清单项**: 数据库错误、AI 请求错误

**验证方案**:
- 触发数据库错误条件（无效 SQL、连接异常）
- 触发 AI 错误条件（无效 API Key、API 超时）
- 从容器日志验证错误已记录
- 验证错误不向用户暴露敏感信息

**预期产出**: 集成到 `ci_logging_test.py` 或新建 `ci_error_logging_test.py`
