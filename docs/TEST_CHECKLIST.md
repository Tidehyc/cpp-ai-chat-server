## 一、后端核心功能测试

### 1.1 用户系统
- [ ] **用户注册**
  - 注册新用户（用户名 + 密码）
  - 重复用户名注册失败
  - 密码长度 < 6 位拒绝
- [ ] **用户登录**
  - 正确用户名密码登录成功
  - 错误密码登录失败（返回 WRONG_PASSWORD）
  - 不存在用户登录失败（返回 USER_NOT_FOUND）
  - 登录后状态变为 online
- [ ] **用户状态管理**
  - `/status online` 设置为在线
  - `/status busy` 设置为忙碌
  - `/status away` 设置为离开
  - `/status offline` 设置为离线
  - `/users` 显示所有非 offline 状态用户
- [ ] **会话 Token**
  - 登录后生成 session_token
  - Token 验证成功
  - 登出后 Token 清除

### 1.2 房间系统
- [ ] **列出房间**
  - `/rooms` 显示 6 个 AI 房间
  - `/list` 显示群聊房间
- [ ] **加入/离开房间**
  - `/join #code` 加入房间
  - `/leave` 离开房间
  - 加入后发送消息广播到房间
- [ ] **创建房间**
  - `/create room test_room` 创建成功
  - 新房间出现在房间列表

### 1.3 AI 对话
- [ ] **@AI 触发**
  - 在房间发送 `@AI 你好` 触发 AI 回复
  - AI 回复格式正确（无 Markdown 符号）
  - AI 回复保存到数据库
- [ ] **私聊 AI**
  - `/msg ai 你好` 私聊 AI
  - AI 回复正确
- [ ] **多轮对话**
  - 连续发送多条消息，AI 能记住上下文
  - `/context` 查看当前上下文大小
  - `/clear` 清空对话上下文
- [ ] **预设使用**
  - `/preset list` 列出预设
  - `/preset use coder` 切换预设
  - 预设影响 AI 回复风格

### 1.4 消息搜索与历史
- [ ] **消息搜索**
  - `/search 关键词` 搜索消息
  - `/search from:user` 按用户搜索
  - `/search in:#room` 按房间搜索
- [ ] **历史记录**
  - `/history @ai 10` 查看 AI 历史
  - `/history #code 20` 查看房间历史
  - `/export @ai` 导出聊天记录
  - `/export @ai format=json` 导出 JSON

### 1.5 群聊功能
- [ ] **消息广播**
  - 加入房间后发送消息
  - 房间内其他用户收到消息
- [ ] **房间隔离**
  - 不同房间消息不串扰

- [ ] **拒绝请求**

- [ ] **查看好友**
  - `/friend list` 显示所有好友

### 2.3 私聊功能

## 八、专项回归：消息已读未读状态

说明：原专项文档已并入主清单，后续统一在本节维护。

- [ ] 数据库 `messages.is_read` 字段存在，默认值为未读（0）
- [ ] 发送私聊后，发送方消息状态显示为未读（单勾）
- [ ] 接收方进入对应会话后，发送方状态更新为已读（双勾）
- [ ] 接收方在线且处于当前会话时，消息自动标记已读
- [ ] `/read <username>` 手动标记已读可用
- [ ] `/unread` 未读计数返回正确
- [ ] `read_confirm` 消息触发前端状态更新
- [ ] 数据库查询结果与界面状态一致（`is_read=0/1`）

建议验证命令：

```bash
sqlite3 data/chat.db "SELECT id,from_user,to_user,is_read,timestamp FROM messages ORDER BY timestamp DESC LIMIT 20;"
```
