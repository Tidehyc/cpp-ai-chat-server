# 数据导出与删除流程草案

版本：Draft
更新时间：2026-05-07

## 1. 当前已支持的导出能力

项目当前已支持聊天记录导出：

- 前端支持导出对话记录
- 后端提供导出接口与命令入口
- 可导出 `txt` 或 `json` 格式的消息历史

相关入口：

- 前端导出按钮：聊天页 / AI 页 / 群聊页的导出功能
- 后端命令：`/export <目标>` 或 `/export <目标> format=json`
- API：`/api/messages/export/<target>?format=txt|json`

## 2. 当前已支持的删除能力

项目当前具备部分删除动作，但尚未形成完整账号级删除流程：

- 删除好友
- 清空本地聊天视图
- 通过数据库备份/恢复和运维操作处理数据回退

## 3. Beta 阶段建议流程

### 导出

1. 用户发起导出请求。
2. 系统生成导出文件。
3. 用户保存导出结果。
4. 如需排障，维护者仅查看必要的元数据，不外发原始内容。

### 删除

1. 用户提交删除申请。
2. 维护者确认删除范围：聊天记录、好友关系、审计记录、账号信息。
3. 在执行前先确认是否需要保留法定或运维所需记录。
4. 执行删除并记录结果。

## 4. 当前缺口

- 缺少自助账号删除按钮/接口
- 缺少明确的数据保留期限
- 缺少删除申请工单化流程

## 5. 后续建议

- 增加账号删除申请表单或管理员命令
- 明确每类数据的保留时长和备份清理策略
- 在正式 GA 前补充法务复核
