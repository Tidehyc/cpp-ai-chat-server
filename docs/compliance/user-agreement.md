# 用户协议草案

版本：Draft
更新时间：2026-05-07

## 1. 服务说明

cpp-ai-chat-server 是一个聊天服务项目，支持私聊、群聊、好友关系、消息搜索、导出、AI 对话和基础运维能力。

## 2. 使用规则

用户在使用服务时应遵守以下规则：

- 不发送违法、侵权、骚扰、欺诈、垃圾广告或恶意内容
- 不尝试绕过权限、限流、审计或安全控制
- 不滥用导出、搜索、批量请求或 AI 接口
- 不冒充他人身份，不伪造消息来源

## 3. 账号与内容

- 用户应对自己的账号安全负责
- 用户发送的内容会被用于消息展示、历史记录、审计和导出
- 维护者可根据系统安全、故障排查或合规需求，查看必要的运维记录

## 4. 禁止行为

包括但不限于：

- 发送恶意链接、注入式内容或自动化攻击流量
- 尝试破坏消息完整性、读写一致性或已读状态
- 传播明显违法或侵权内容
- 利用系统缺陷绕过登录、好友、房间或管理员限制

## 5. 处理措施

对于违反规则的行为，维护者可以采取以下措施：

- 提示或警告
- 限流或临时封禁
- 删除违规内容或限制相关功能
- 保留必要审计记录

## 6. 免责声明

- 本项目当前处于 Beta / 试运行阶段，服务可用性和功能范围可能变化
- 本草案不是最终商用协议，正式上线前需要复核和修订
- 使用者应自行评估其数据使用、备份与合规要求
